### <a name="_3bfxc9a45514"></a>**Функциональные требования**

| **№** | **Use Case**                          | **Описание**                           |
|-------|---------------------------------------|----------------------------------------|
| UC1   | Передача ставок из АБС в кол-центр    | Ежедневное обновление ставок через API |
| UC2   | Генерация файла ставок для партнёра   | Выгрузка в CSV/SFTP раз в сутки        |
| UC3   | Отображение ставок в CRM кол-центра   | Интерфейс для операторов               |

### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| **№** | **Требование**                    |
|-------|-----------------------------------|
| NF1   | Задержка передачи ставок < 1 часа |
| NF2   | Шифрование файлов (PGP/GPG)       |
| NF3   | Совместимость с текущей CRM       |

### <a name="_qmphm5d6rvi3"></a>**Решение**


1. `context.puml`
2. `components.puml`

**Логика решений:**  
- Для внутреннего кол-центра: REST API из АБС (реализует IT-отдел банка)
- Для партнёра: SFTP + шифрование (PGP), так как API недоступен
- 
### <a name="_bjrr7veeh80c"></a>**Альтернативы**
1. **API для партнёра**  
   - *Плюсы:* Реальное время  
   - *Минусы:* Требует доработок у партнёра

2. **Общее облачное хранилище**  
   - *Плюсы:* Простота
   - *Минусы:* Риски безопасности

**Недостатки, ограничения, риски**
1. Задержки в выгрузке файлов → дублирование ставок вручную 
2. Ошибки шифрования → утечка данных
