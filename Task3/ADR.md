### <a name="_qmphm5d6rvi3"></a>**Решение**
1. `context.puml` - Контекстная диаграмма C4:  
   - Внешние системы: SMS-шлюз, БКИ  
   - Основные компоненты: Сайт, Интернет-банк, АБС, Кол-центр  

2. `containers.puml` - Диаграмма контейнеров:  
   - **Интернет-банк**:  
     - Веб-интерфейс (React.js)  
     - API Gateway (.NET Core)  
     - Кеш ставок (Redis)  
   - **АБС**:  
     - Модуль депозитов (PL/SQL)  
     - Интеграционный слой (Java)  

**Логика решений:**  
- Использован API Gateway для изоляции АБС от прямых вызовов (требование R1)  
- Redis для кеширования ставок (решение проблемы медленных справочников)  
- RabbitMQ для асинхронной обработки заявок (альтернатива Kafka из-за ограничений интернет-банка)  

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
1. **Прямая интеграция с АБС**  
   - *Плюсы:* Проще реализация  
   - *Минусы:* Нарушает требование R1, риск перегрузки АБС  

2. **Использование Kafka**  
   - *Плюсы:* Лучшая масштабируемость  
   - *Минусы:* Требует обновления интернет-банка  

**Недостатки, ограничения, риски**
1. Перегрузка АБС при пиковых нагрузках (решение: лимиты запросов)  
2. Задержки в синхронизации данных (решение: увеличение частоты выгрузок)  
3. Недостаточная экспертиза по RabbitMQ (решение: обучение команды)
