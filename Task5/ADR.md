### <a name="_qmphm5d6rvi3"></a>**Решение**
Приведите диаграммы контекста и контейнеров в модели C4. Опишите там основные компоненты и интеграции всех элементов решения. 

Также опишите, какой логикой вы руководствовались в ходе принятия решений и выбора технологий. Не забывайте, что необходимо учесть все функциональные и нефункциональные требования.

1. `context.puml` - Контекстная диаграмма C4
2. `components.puml` - Диаграмма компонентов

**Логика решений:**  
Для новых клиентов (сайт):
- Быстрый предварительный скоринг через API БКИ с кешированием (Redis)
- Мгновенный ответ без интеграции с АБС
Для текущих клиентов (интернет-банк):
- Проверка предодобренных предложений через REST API
- Асинхронная обработка сложных заявок через RabbitMQ

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
1. **Прямая интеграция АБС**  
   - *Плюсы:* Проще реализация  
   - *Минусы:* Перегрузка АБС 

2. **Собственный кеш данных БКИ**  
   - *Плюсы:* Уменьшение запросов  
   - *Минусы:* Риск устаревания данных
